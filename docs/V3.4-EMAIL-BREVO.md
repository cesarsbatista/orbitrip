# Orbitrip V3.4 — e-mail de acesso com Brevo (plano gratuito)

Este procedimento conclui a entrega de códigos OTP de seis dígitos do Supabase para as duas contas da Orbitrip. **Não compartilhe chaves SMTP, códigos recebidos nem senhas no chat ou no GitHub.**

## Estado atual

- Supabase Orbitrip: https://supabase.com/dashboard/project/esusriurebspnmrwoabq
- Banco, permissões e chave pública: configurados.
- **Ainda pendente:** conta remetente de e-mail, SMTP e templates. Não declarar o login pronto antes de testar o primeiro envio.
- **Custo do Brevo Free:** R$ 0 como assinatura do plano, com franquia atualmente informada de até 300 e-mails por dia. Veja as condições atuais da conta; recursos específicos podem sofrer revisão.

## 1 — Abrir uma conta Brevo gratuita

1. Entre em https://www.brevo.com/pt/ e escolha o plano **Free**, sem migrar para plano pago.
2. Confirme seu e-mail e conclua as verificações solicitadas pelo serviço.
3. Crie um remetente em **Configurações → Remetentes, domínios e IPs → Remetentes**. Use nome **Orbitrip** e um e-mail de remetente que você controla; confirme o código enviado pela Brevo.

A Brevo recomenda autenticar um domínio próprio (DKIM/DMARC) para melhor entrega. Com endereço gratuito, a Brevo pode substituir o endereço de envio por um domínio técnico; a conta também pode exigir verificação/ativação do recurso transacional. **Não compre um domínio nem plano adicional sem decidir antes.** Primeiro teste a opção gratuita disponível.

## 2 — Ativar o SMTP transacional

1. Na Brevo, procure **Transactional → SMTP & API** ou abra https://app.brevo.com/settings/keys/smtp.
2. Abra a aba **SMTP**; se necessário, gere uma **chave SMTP** (não confundir com API key).
3. Copie o **login SMTP** exibido na sua conta e a chave SMTP em local seguro. **Não os envie nesta conversa.**
4. Verifique se a conta permite o envio transacional. Caso a opção não esteja ativa, siga a verificação solicitada pela própria Brevo.

Dados públicos para a configuração:

| Campo | Preenchimento |
| --- | --- |
| SMTP Host | `smtp-relay.brevo.com` |
| SMTP Port | `587` (STARTTLS) |
| SMTP User | Login SMTP mostrado na Brevo — pode ser diferente do seu e-mail principal |
| SMTP Password | Chave **SMTP** gerada na Brevo — mantenha privada |
| Sender Name | `Orbitrip` |
| Sender Email | Remetente verificado na Brevo |

## 3 — Inserir SMTP no Supabase

1. Abra [Supabase — Authentication](https://supabase.com/dashboard/project/esusriurebspnmrwoabq/auth/providers) e procure **SMTP Settings**, às vezes em **Authentication → SMTP Settings** ou **Authentication → Settings**.
2. Ative **Custom SMTP**.
3. Preencha os campos usando a tabela acima.
4. Salve e teste o envio com um endereço **que você controla**.

O Supabase não permite envio a e-mails externos ao time pelo serviço padrão. O SMTP customizado resolve essa limitação quando o provedor aceita o remetente, destinatário e as regras de envio.

## 4 — Mudar o template para código OTP

1. Acesse [Supabase — Email Templates](https://supabase.com/dashboard/project/esusriurebspnmrwoabq/auth/templates).
2. Abra o template **Magic Link**, usado pelo fluxo `signInWithOtp()`.
3. Cole o HTML preparado no repositório: [`supabase/email-otp-template.html`](../supabase/email-otp-template.html). O trecho **`{{ .Token }}`** deve permanecer exatamente assim.
4. Para novos cadastros, confira também o template de **Confirm signup** e utilize a variável `{{ .Token }}` se o primeiro acesso enviar uma mensagem de confirmação em vez do código esperado.
5. Mantenha a confirmação de e-mail habilitada. Não desative essa proteção como atalho para os testes.

A interface da Orbitrip utiliza `verifyOtp({ email, token, type: "email" })`.

## 5 — URL do site

Na página [Authentication → URL Configuration](https://supabase.com/dashboard/project/esusriurebspnmrwoabq/auth/url-configuration), configure a **Site URL** com o endereço publicado e real da Orbitrip e adicione as URLs de redirecionamento necessárias.

Antes de definir a URL, confirme em **GitHub → repositório → Settings → Pages** qual é o endereço publicado. Não assuma automaticamente a URL do GitHub Pages.

## 6 — Teste final

- Confirme que recebeu o código de seis dígitos e conseguiu entrar.
- Teste seu primeiro cadastro e depois um novo login; ambos precisam funcionar.
- Em seguida, peça à sua esposa que entre com o próprio e-mail.
- Compartilhe a viagem com permissão **Editor**; ela aceita com link ou código.
- Faça uma alteração pequena, confirme a sincronização e teste a outra conta.
- Antes de migrar os dados locais, exporte um backup JSON.
