## Ação manual obrigatória 1 — habilitar o e-mail com código

A conexão atual permite controlar o banco pelo ChatGPT, mas **não expõe controles de configuração dos modelos de e-mail do Supabase Auth**.

1. Acesse [Supabase → Authentication → Email Templates](https://supabase.com/dashboard/project/esusriurebspnmrwoabq/auth/templates).
2. Escolha o modelo **Magic Link** (e confirme se há modelo específico de confirmação de cadastro, conforme a configuração de seu projeto).
3. Substitua o corpo da mensagem pelo conteúdo de [`supabase/email-otp-template.html`](../supabase/email-otp-template.html). Ele inclui `{{ .Token }}`, necessário para mostrar o código temporário de seis dígitos.
4. Salve. Em **Authentication → Providers → Email**, mantenha o e-mail habilitado e a confirmação de e-mail ativa.

O formulário da Orbitrip envia o código via `signInWithOtp()` e verifica com `verifyOtp({type: "email"})`. Não publique senhas, tokens ou chaves secretas.

## Ação manual obrigatória 2 — entrega a destinatários externos (SMTP)

**Atenção:** a documentação atual do Supabase esclarece que o serviço padrão de envio de e-mails de projetos hospedados envia apenas para **endereços de membros da equipe da organização**. Para usar a Orbitrip com sua esposa, que não deve precisar acessar o painel administrativo do projeto, configure **SMTP próprio** ou **Send Email Hook**.

- [Supabase — configuração de SMTP](https://supabase.com/docs/guides/auth/auth-smtp)
- [Supabase — limites e teste dos fluxos de autenticação](https://supabase.com/docs/guides/auth/testing-auth-flows)

Pode ser um serviço com plano gratuito adequado ao uso pessoal, sujeito aos limites e regras do fornecedor. Os dados de SMTP são **secretos e devem ser inseridos diretamente no painel Supabase**, nunca no GitHub ou no código do navegador.

Não recomendamos adicionar sua esposa como administradora do projeto Supabase apenas para contornar o limite do e-mail padrão.

## Ação manual obrigatória 3 — URL de acesso

Acesse [Supabase → Authentication → URL Configuration](https://supabase.com/dashboard/project/esusriurebspnmrwoabq/auth/url-configuration).
Defina **Site URL** e a lista de URLs permitidas com o **domínio HTTPS real** da Orbitrip, conforme publicado no GitHub Pages ou serviço escolhido. Não presuma que o GitHub Pages está ativo sem confirmar em **Settings → Pages**.

## Teste com as duas contas

1. Confirme que o site Orbitrip está publicado e que `config.js` está sendo carregado.
2. Faça backup JSON de suas viagens locais antes do primeiro login.
3. Digite seu endereço de e-mail na tela de login; confira o **código de seis dígitos**.
4. Na conta, selecione **Copiar minhas viagens para a nuvem** para migrar as viagens que estavam no navegador, sem excluir as cópias locais.
5. Abra a viagem, clique em **Compartilhar** e gere um convite de **Editor**.
6. Compartilhe o link ou código com sua esposa. Ela entra pelo próprio e-mail e aceita o convite.
7. Teste alterações por um e outro. Atualizações usam Realtime; alterações simultâneas incompatíveis produzem aviso de conflito e a opção de exportar rascunho. Não existe mesclagem automática.

## Segurança e limitações

- **Nunca exponha:** `service_role`, `sb_secret_...`, senha do banco, senha de SMTP, token de usuário.
- **Publicável:** URL do projeto e `sb_publishable_...` com regras RLS ativas.
- O Supabase gratuito pode pausar projetos por inatividade ou alterar cotas.
- O navegador precisa estar conectado para manter a conta sincronizada.
- A estrutura SQL e os privilégios foram verificados, mas **os testes de login e colaboração com duas contas reais ainda não foram executados**.
